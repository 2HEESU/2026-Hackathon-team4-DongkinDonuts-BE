## 컨벤션
1. 작업 전 반드시 pull 받고 진행

2. `requirements.txt` 변경사항 있을 시
   - 소통 채널 활용하여 공지
   - `README.md`의 `사용 라이브러리` 항목 수정
   - 아래 명령어 수행

     ```bash
     pip install -r requirements.txt
     ```
